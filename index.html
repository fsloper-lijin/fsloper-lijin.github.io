关于我

完整介绍 →

全栈对我来说不是「什么都会一点」，而是能独自把一个产品从想法推到线上： 从界面、接口、数据模型，到部署和监控。

我喜欢这件事里那种没被切割的连续性——改一行文案时，知道它会怎么流过缓存、 落到哪张表、最后在哪个面板上被人看见。

这个站是我自己手写出来的，没有框架。算是一种提醒： 工具可以换，基本功不能省。

  • TypeScript / JavaScript主力
  • React / Vue前端
  • Node.js / Python服务端
  • PostgreSQL / Redis数据层
  • Docker / Linux部署运维
